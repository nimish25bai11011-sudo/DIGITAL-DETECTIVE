# Project Statement

## Project Title

Digital Detective - Crime Investigation System

---

## Problem Statement

Crime investigation involves collecting and organizing information
from different sources such as suspects, evidence, clues and interviews.

Managing this information manually can make it difficult to keep track
of investigation details.

Digital Detective provides a simple command-line system for organizing
case information and performing basic investigation analysis.

---

## Objectives

The main objectives of this project are:

- To develop a Java-based crime investigation system.
- To apply Object-Oriented Programming concepts.
- To organize suspects, evidence, clues and interviews.
- To calculate and display suspicion scores.
- To generate a final investigation report.
- To provide a simple and easy-to-use command-line interface.

---

## Scope

The project focuses on a small-scale crime investigation simulation.

The system allows users to:

- Create a crime case.
- Add suspects.
- Record evidence.
- Add investigation clues.
- Conduct suspect interviews.
- Identify possible contradictions.
- Calculate suspicion scores.
- Analyze suspects.
- Generate a final investigation report.

The project is designed for educational purposes and does not replace
real criminal investigation procedures.

---

## Target Users

The intended users of the project are:

- Students learning Java.
- Beginners learning Object-Oriented Programming.
- Students developing command-line applications.
- Users interested in crime investigation simulations.

---

## High-Level Features

1. Case creation and management
2. Suspect management
3. Evidence management
4. Clue management
5. Suspect interviews
6. Basic contradiction detection
7. Suspicion score analysis
8. Final investigation report

---

## Expected Outcome

The project demonstrates how Java programming concepts can be used to
create a modular command-line application for organizing investigation
information.

The system processes user input, stores investigation data during
execution and provides basic analysis through suspicion scores and a
final case report.

---

## Technologies

- Java
- Object-Oriented Programming
- ArrayList
- Scanner
- Command-Line Interface
- Git and GitHub

---

## Project Limitations

- Data is stored only during program execution.
- No database is currently used.
- The system uses a command-line interface.
- Suspicion analysis is based on simple predefined rules.
- The project is an educational simulation.

---

## Future Scope

Future versions of the project can include:

- Database integration.
- File-based case storage.
- Investigator login.
- Case search and filtering.
- Improved contradiction detection.
- Graphical User Interface.
- Case history and relationship analysis.
